# CMA Study Hub V3

Professional mobile-first CMA Intermediate study website for GitHub Pages.

### Features
- Responsive professional homepage
- 8 CMA Intermediate papers (Syllabus 2022 structure)
- Dynamic subject and article pages
- Site-wide search
- Dark mode
- Mobile menu
- Working MCQ test with score
- WhatsApp + Telegram floating buttons
- About, Contact, Privacy, Disclaimer and 404 pages
- robots.txt + sitemap.xml + .nojekyll

### Before going live
Edit `script.js` and replace `S.wa` and `S.tg` with your real WhatsApp/Telegram details. Replace the email in `contact.html`.

Upload the files INSIDE this ZIP to the root of your existing `main` branch. Do not upload only the ZIP. Keep `index.html` at the root.

This is an independent student resource, not an official ICMAI site. Verify current syllabus, amendments and notifications with ICMAI.
